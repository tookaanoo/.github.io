02 PERFORMANCE

XIRR と TWR、
2つの目で見る。

「あなたの実利回り」を表す XIRR と、「運用力」を表す TWR。FIRE 志向の積立スタイルでは、両方を見ることで真実が見える。

  • XIRR(メイン):ドルコスト平均法・スポット買付の成果が反映される実利回り
  • TWR(補助):入金タイミングを排除した運用力。ランキングや他人との比較に
  • ベンチマーク比較:オルカン・S&P500・TOPIX と XIRR/TWR の両軸で比較
  • 拠出効果 vs 運用効果:「自分のお金で増えた」vs「市場が増やしてくれた」を分離

03 TAX

税金を、
味方にする。

複雑な日本の税制を、シンプルに見える化。NISA・外国税額控除・配当課税の最適化まで、確定申告の節税ポイントを自動で提示。

  • NISA枠管理:年間枠・生涯枠・売却時の枠復活を自動計算
  • NISAの落とし穴:米国株配当の取戻不可額をアラートで警告
  • 配当課税3パターン比較:申告不要・申告分離・総合課税の節税額を自動判定 (Premium)
  • 損益通算と還付見込み:多めに源泉徴収された分の還付額を可視化 (Light)
  • 外国税額控除:課税口座の米国源泉から、確定申告で取り戻せる額を試算 (Light)

05 SIMULATION

あなただけの、
到達予測。

入金・配当・運用利回り、すべて「あなたの実績」から逆算。「もし月積立を¥3万増やしたら?」What-If も、リアルな実績ベースで試算できる。

  • 実績ベース推定:あなたのこれまでの XIRR・入金力・配当利回りからパラメータを抽出
  • 3シナリオ表示:楽観(実績+3%)・中立(実績維持)・悲観(実績-3%)で比較
  • What-If:月積立 ±¥3万/±¥5万、想定年率 ±3% で達成時期がどう変わるかを瞬時に
  • リバランス提案:目標配分と現在の乖離をアラート (Light)
  • AI月次レポート:パーソナライズされたアクション提案 (Premium)
