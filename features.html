02 PERFORMANCE

XIRR と TWR、
2つの目で見る。

「あなたの実利回り」を表す XIRR と、「運用力」を表す TWR。FIRE 志向の積立スタイルでは、両方を見ることで真実が見える。

  • XIRR（メイン）：ドルコスト平均法・スポット買付の成果が反映される実利回り
  • TWR（補助）：入金タイミングを排除した運用力。ランキングや他人との比較に
  • ベンチマーク比較：オルカン・S&P500・TOPIX と XIRR/TWR の両軸で比較
  • 拠出効果 vs 運用効果：「自分のお金で増えた」vs「市場が増やしてくれた」を分離

03 TAX

税金を、
味方にする。

複雑な日本の税制を、シンプルに見える化。NISA・外国税額控除・配当課税の最適化まで、確定申告の節税ポイントを自動で提示。

  • NISA枠管理：年間枠・生涯枠・売却時の枠復活を自動計算
  • NISAの落とし穴：米国株配当の取戻不可額をアラートで警告
  • 配当課税3パターン比較：申告不要・申告分離・総合課税の節税額を自動判定 PREMIUM
  • 損益通算と還付見込み：多めに源泉徴収された分の還付額を可視化 LIGHT
  • 外国税額控除：課税口座の米国源泉から、確定申告で取り戻せる額を試算 LIGHT

04 COMMUNITY

1人じゃない、
経済的自立。

同じ銘柄を持つ仲間とつながる。煽らない、ランキング化しない、当事者性で語る。SNS の3層設計で、健全なコミュニティを。

  • ホルダーコミュニティ：同じ銘柄を持つ人の輪。額はレンジ表示のみ、人数と保有期間で語る
  • 応援（チア）スタンプ：ナイスホールド・おめでとう・お疲れさま。労いと連帯の3種
  • 「なぜ私は持つか」保有理由：一人称で書く。保有期間で裏付け、公開範囲はオプトイン
  • まとめ通知（ダイジェスト）：フォロー先の動きを遅延＋まとめて配信。週次＝無料 / 日次＝Light / 即時＝Premium
  • FIRE ステージ7段階：同じ資産帯でフェアに比較、XIRR/TWR の2軸切替
  • Creator還元：フォロワー数に応じて Premium 機能が無料に

07 BROADCAST

静かに記録、
燃える瞬間だけ発信。

普段は静かに資産を記録する。マイルストーン到達やステージアップなど、発信に値する瞬間だけプロンプトが立ち上がる。あなたの実績データを引用するから、煽りや誇張は構造的に防がれる。

  • モーメント検知：マイルストーン・連続記録・大きな本日損益など、発信どきを自動検知
  • 実績データ引用：発信できるのは自分の記録に紐づくもののみ。捏造できない設計
  • 額の出し方を選べる：レンジ・率・非表示から選択。絶対額は既定で出さない
  • 一人称フレーミング：「これを買え」ではなく「自分はこうした」。当事者性で語る
  • 発信スタジオは全機能無料 無料

08 TOOLS

比較して、
見守って、気づく。

銘柄選びの精度を上げるツール群。最大10銘柄の横並び比較、ウォッチリストと価格アラートで気になる銘柄を見守る。分析ハブには FIRE シミュレーション・ベンチマーク・リスク分析・リバランスをすべて集約。

  • 銘柄比較：最大10銘柄を横並び比較。価格推移の重ね描き、財務指標・配当利回りを一覧で（無料3銘柄 / Light以上10銘柄）
  • ウォッチリスト：気になる銘柄を保有前から見守る（無料10銘柄 / Light 30銘柄 / Premium 100銘柄）
  • 価格アラート：上抜け・下抜けの通知（無料3件 / Light 10件 / Premium 30件）
  • 分析ハブ：FIREシミュレーション・ベンチマーク・リスク・リバランスを1つの画面に集約
  • 口座別ページ：証券会社軸での内訳。NISA枠の使用状況も一目で
