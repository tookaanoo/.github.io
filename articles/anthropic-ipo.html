Anthropicの
新規上場
｜長期投資家の目線

AI「Claude」の開発元。売上は急増、赤字の大半は評価損。独自のガバナンスを確認する

売上は前年同期の約14倍

AI「Claude」を開発するAnthropicが、2026年10月26日に、上場申請書（S-1）を公開した。Nasdaqに、ティッカー「ANT」で上場する予定。2026年1〜6月の売上は162.9億ドルで、前年同期の約14倍。

純損失の約9割は評価損

同期間の純損失は807.5億ドル。ただし、その約9割（723.9億ドル）は、転換社債などの評価損（会社の評価額が上がったことによる会計上の損失）。本業の営業損失は6.9億ドルまで縮小した。

議決権は信託と創業者に

公益法人（PBC）で、議決権は、長期利益信託（LTBT）と創業者に集中する。長期では、売上の伸び、営業損益、計算資源の費用、顧客の集中、ガバナンスを確認する。この記事は、申込みの是非を判断するものではない。

1. どんな会社か

Anthropicは、2021年1月に設立された、米国サンフランシスコの会社です。大規模言語モデル「Claude」と、それを使う製品を、企業や個人に提供しています。

  • Claude Platform：企業が、自社の製品や業務にClaudeを組み込むための開発環境（API）。
  • Claude Code：ソフトウェア開発を、計画・作成・テスト・修正まで行うコーディングエージェント。
  • Claude Cowork：パソコン上の操作も含めて、調査・資料作成・分析などの仕事を進めるエージェント。2026年9月から、Claude.aiとの統合を始めた。

Claudeは、Amazon（AWS）、Google（GCP）、Microsoft（Azure）の3大クラウドからも使えます。売上の多くは、使った量（トークン）に応じた課金と、定額の利用プランです。

2. 上場の概要

  • 市場：Nasdaq Global Select Market（ティッカー「ANT」、Class A普通株）。
  • 主幹事：ゴールドマン・サックスとモルガン・スタンレー（引受人の代表）。
  • 価格帯と株数：S-1の時点では、決まっていない（空欄）。上場日も、未定。
  • 日本の投資家にも関係：S-1には、公募に、日本を含む国・地域（オーストラリア、カナダ、欧州の一部、日本、スイス、英国）での募集が含まれる、と書かれている。ただし、日本の取引所には上場しない。
  • 調達資金の使い道：運転資金、計算資源やインフラへの投資、人材の採用など（会社の説明）。一部は、社員の株式報酬にかかる源泉税の支払いに充てる。

4. 純損失の中身：大半は評価損

  • 2026年1〜6月の純損失807.5億ドルのうち、723.9億ドルは「転換社債、デリバティブ負債、SAFEの公正価値の変動」です。会社は、評価額が上がったことで、発行済みの転換社債の公正価値が増えたためと説明しています。
  • これは、会計上の損失で、その分の現金が出ていったわけではありません。本業の採算を見るには、営業損益を分けて見ます。
  • 2025年通期の純損失（419.7億ドル）にも、同じ評価損（343.1億ドル）と、訴訟の和解金（15億ドル、Bartz settlement）が含まれます。

5. 費用の構造：最大は計算資源

AIの学習と提供には、大量の計算資源（AI向けの半導体、データセンター、電力など）が必要です。2026年1〜6月の計算資源とインフラの費用は89.5億ドルで、売上の約55%でした。前年同期は、費用が売上の約2倍あったため、比率は大きく下がりました。会社は、計算資源の追加の確保と、自社のデータセンターの拡大を、成長戦略に挙げています。

8. ガバナンス：議決権は、信託と創業者に集中

Anthropicは、デラウェア州の公益法人（PBC）です。取締役は、株主の金銭的な利益に加えて、事業の影響を受ける人の利益と、会社の公益目的（「人類の長期的な利益のための、先進的なAIの責任ある開発と維持」）を、両立させる義務を負います。

株式議決権持つ人
Class A1株1票今回の上場で売買される株式（一般の投資家）
Class F1株で、議決権全体の50.1%創業者7人が参加するLLC（上場の直前に1株を発行）
Class T取締役の過半数を選ぶ長期利益信託（LTBT）。財務的な利害を持たない5人の受託者
Class N原則なし自社の公益基金（株式の5%を拠出）など
Class E特定の取締役の指名などに限る（S-1の資本構成の表による）
  • LTBT（長期利益信託）は、取締役の過半数を選び、解任できる。ただし、日々の経営や戦略には関わらない（会社の説明）。
  • 創業者LLCは、Class F株1株で、議決権全体の50.1%を持つ。このため、Nasdaqの「支配株主がいる会社（controlled company）」に当たる。
  • 株式の5%（Class N）を、自社の公益基金に拠出した。株価が上がるたびに、追加で拠出する仕組みもある。創業者は、それぞれ、持ち分の80%を慈善に充てると誓約している。

9. 会社が挙げる主なリスク

S-1の「リスク要因の要約」から、主なものを抜き出しました（要約・言い換え）。

  • 最先端のモデルを作り続けられるか。できなければ、事業に影響する。
  • 計算資源を十分に確保できるか。半導体や電力など、重要な投入物の制約もある。
  • 競争が激しい。市場の成長が想定より遅い可能性もある。
  • AIによる害。悪用や、意図しない動き（自律的な行動を含む）による、評判・訴訟・規制のリスク。
  • 少数の顧客と配布チャネルへの依存。大手クラウドは、供給者・出資者・顧客でもあり、利益相反がありうる。
  • 規制と政治の不確実性。S-1によると、2026年2月、大量監視や完全自律型兵器への利用に反対する同社の立場をめぐり、米大統領が連邦機関に同社の技術の利用停止を指示し、国防当局（Department of War）が同社を「サプライチェーン上のリスク」に指定するよう指示した。会社は提訴し、2026年8月27日に連邦地裁で、おおむね会社側の主張を認める判断を得た、としている。
  • 創業者、経営陣、主要な技術者への依存。
  • 株式の仕組み。Class Aの株主は、支配権の変更を含む重要な決定に、影響を与えにくい。公益法人として、短期の財務的な利益と、ぶつかる場合がある。

10. 上場後の決算で、何を確認するか

確認する項目現在の数字なぜ重要か外れた場合確認する時期
① 売上の伸び2026年1〜6月は162.9億ドル（前年同期の約14倍）急成長が続くか。会社も「過去の成長率は将来を示さない」としている伸びが鈍り、計算資源への投資の回収が遅れる四半期決算（上場後）
② 営業損益2026年1〜6月は−6.9億ドル（前年同期は−21.4億ドル）評価損を除いた、本業の採算費用の増加が売上の伸びを上回り、赤字が広がる四半期決算
③ 計算資源の費用と確保費用は売上の約55%。大規模な確約（コミットメント）がある最大の費用で、モデルの競争力にも直結する確保できない、または費用の比率が下がらない四半期決算、10-Kの確約の注記
④ 顧客とチャネルの集中売上と売掛金の相当部分が、少数の顧客・配布チャネルに依存（会社の説明）大手クラウド（AWS・GCP・Azure）は、販売経路であり、出資者・供給者でもある主要な顧客やチャネルの支出が減る年次報告書（10-K）のリスク・顧客の注記
⑤ ガバナンス議決権は、LTBTと創業者LLCに集中。公益法人（PBC）Class Aの株主は、重要な決定に影響を与えにくい公益と株主の利益の両立が、株価に影響しうる株主総会、取締役の選任
⑥ ロックアップの解除最終的な目論見書の日付から180日（会社の開示）既存株主の売却が始まりうる時期解除の前後で、需給が動く上場日から約半年後

数字は、S-1（2026年10月26日提出）より。上場後の決算の日程と、開示される項目は、会社のIR（www.anthropic.com）とSECの提出書類で確認してください。

11. 長期投資家は、どう受け止めるか

  • 純損失と営業損益を、分けて見る。純損失の大半は評価損で、本業の採算は、営業損益に表れる。
  • 計算資源の費用の比率を、決算ごとに見る。売上の伸びに対して、費用の比率が下がり続けるかが、採算の焦点。
  • 顧客の数と、集中の両方を見る。大口の顧客は急増しているが、少数の顧客・チャネルへの依存も、会社自身がリスクに挙げている。
  • ガバナンスの仕組みを理解する。Class Aの株主は、議決権の上では、経営に大きな影響を与えにくい。
